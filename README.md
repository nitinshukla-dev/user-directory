# User Directory

A simple web app for adding people to a directory. Each user appears as a profile card with their name, role, bio, and photo.

## Features

- Add a user with a name, role, bio, and photo URL
- Remove a user from the directory
- View profiles in a responsive card layout

## Built With

- HTML
- JavaScript
- Tailwind CSS

## How to Run

1. Download or clone this repository.
2. Open the HTML file in a web browser.
3. Fill in the form and select **Submit** to add a user.
4. Select **Remove** on a profile card to remove that user.

## Note

Users are stored only while the page is open. Reloading the page clears the directory.
